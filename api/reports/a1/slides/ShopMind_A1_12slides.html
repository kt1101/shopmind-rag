05 / DENSE VÀ HYBRID RRF

Dense và Hybrid RRF còn yếu

Dense text và text → image đều Recall@10 = 0,0125; BM25 tương ứng 37/80.

01

Encoder / domain

SigLIP2 chưa fine-tune riêng
cho product retrieval trên ABO.

02

Representation

search_text dài so với query ngắn
có thể làm loãng tín hiệu.

03

Tính nhất quán

Chưa pin model_revision; kiểm tra
padding và encode đơn lẻ/batch.

04

Qrels

Một positive/query; semantic neighbor
hợp lý vẫn có thể không được chấm.

RRF giảm Recall 29,7% so với BM25. Các nguyên nhân dense yếu cần ablation để xác nhận.
